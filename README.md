# 🧠 Shahmeer's MindPulse AI OS

> A full-stack personal productivity, mental focus, and cognitive performance tracking system built with Django, JavaScript, and Bootstrap 5.

---

## 🌟 Overview

**MindPulse AI OS** is a central command center designed to optimize daily workflow, track habit consistency, manage tasks efficiently, and boost deep-work sessions. It combines interactive focus tools with responsive web architecture, creating a unified workspace for high performance.

---

## 🔥 Key Features

- **⚡ Multi-Tool Focus Hub:** Integrated Focus Timer (Pomodoro), drift-free accurate Stopwatch (Timestamp-based), and custom Audio Alarms.
- **📋 Task & Focus Register:** Complete task management system with real-time active tasks, dynamic status toggling, and a collapsible **Completed History Vault**.
- **✨ Neural Quests & Streaks:** Gamified habit tracking to log daily mental output and progress momentum.
- **🎬 Media Vault:** Curated space for focus-enhancing audio, motivational media, and learning content.
- **📊 Analytics Ready:** Designed for dynamic progress visualization using Chart.js.
- **🎨 Responsive UI:** Custom dark-themed navigation sidebar with smooth layout expansion and clean Bootstrap 5 styling.

---

## 🛠️ Tech Stack

- **Backend:** Python, Django 6.1.2
- **Frontend:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5, FontAwesome 6
- **Database:** SQLite3 (Development)
- **Version Control:** Git, GitHub
